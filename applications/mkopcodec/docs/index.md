# mkopcodec

`sqlite::compiler::tooling::mkopcodec` -- SRS 002 RR-5's complete C++
replacement for `applications/mkopcodec-legacy/mkopcodec.tcl`, a build-time
generator application (not a runtime library) that has no `sqlite3`
dependency and is therefore unblocked rather than facade-gated (SRS 002
S5.4.2).

## What it does

Reads `opcodes.h` (generated by `mkopcodeh`/`mkopcodeh-legacy`) and emits
`opcodes.c`: the `sqlite3OpcodeName()` function and its `azName[]` table of
human-readable opcode names/synopses, used when disassembling a VDBE
program during tracing or `EXPLAIN`.

## Namespace and API surface

| Header | Contents |
|---|---|
| `generator.hpp` | `sqlite::compiler::tooling::mkopcodec::generate(std::istream&) -> std::string`, plus `detail::trim`/`detail::append_printf` helpers |

`main.cpp` is a thin CLI wrapper matching the legacy tool's contract
exactly: one file argument (the path to `opcodes.h`), output on stdout.

## Legacy source traceability

Ported from `applications/mkopcodec-legacy/mkopcodec.tcl` (relocated from
`tool/mkopcodec.tcl` by SRS 002 RR-4). Scans `#define OP_<name> <number>`
lines (optionally carrying a trailing `synopsis: <text> */` comment,
greedy-matched exactly as the legacy TCL regex `.* \*/` is) and reproduces
the fixed preamble/table/postamble byte-for-byte.

The only intentional output difference from the legacy tool is the
provenance banner comment naming *this* tool's path instead of the legacy
one's -- SRS 002 TR-1's explicitly-anticipated, documented exception,
normalized away by `tool/check-generator-parity.sh` before the RR-7
`generator_parity_mkopcodec` CTest comparison (run against the real,
already-generated `opcodes.h` the main codegen pipeline produces).
Everything else is byte-for-byte identical, verified by that same test.

## Building and running tests independently

```sh
cmake -S applications/mkopcodec -B build-mkopcodec
cmake --build build-mkopcodec
ctest --test-dir build-mkopcodec
```

Or, as part of the full workspace build, run just this application's tests
with `ctest -R sqlite-mkopcodec`, and the RR-7 parity check against the
legacy tool with `ctest -R generator_parity_mkopcodec`.
